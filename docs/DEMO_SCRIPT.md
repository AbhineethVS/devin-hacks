## Famous code shelf (check each URL loads before recording)
- Apollo 11 guidance computer (`chrislgarry/Apollo-11`): any `.agc` file. Assembly, so Play file only.
- Quake III `q_rsqrt` (`id-Software/Quake-III-Arena`, `code/game/q_math.c`)
- Linux kernel: a small file from `torvalds/linux`, e.g. `kernel/` something short
- Doom (`id-Software/DOOM`): `linuxdoom-1.10/m_random.c`, which is tiny and iconic

## Recording tips
- Record the screen with system audio (OBS).
- Headphones on so the mic doesn't pick up the music.
- Make the editor font large.
- Keep a backup recording of every segment.
